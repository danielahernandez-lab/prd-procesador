# prd-procesador

Skill para Claude Code que escribe el PRD de una integración con un nuevo procesador de pagos (banco, wallet, PSP, agregador): transferencias entrantes/salientes y métodos de pago alternativos.

Entrevista al usuario, completa una plantilla de 16 secciones, cierra primero lo que más sorprende tarde (confirmación, mapeo de estados y errores, conciliación) y deja lo que no se sabe como preguntas abiertas en lugar de inventarlo.

## Instalar

```bash
npx skills add danielahernandez-lab/prd-procesador
```

## Usar

Pide, por ejemplo: "Necesito el PRD para integrar una wallet como transferencia entrante en Perú".
